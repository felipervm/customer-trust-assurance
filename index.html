What changes after a fixture refresh?＋

The strict baseline gate intentionally blocks every old-version fixture. The refreshed fixtures are constructed with matching claims and current citations. These counts do not measure an LLM’s accuracy or prove a production improvement.

What does this prototype leave untested?＋

No live agent, retrieval system, confidential content, real questionnaire or security assessment is connected. Structured claim comparison does not evaluate arbitrary language or discover unknown security gaps.

A SHA-256 fingerprint identifies a local fixture record. It does not authenticate a real document or prove a security control exists.

How would I maintain an AI-assisted workflow?＋

Proposed next step: version approved references and agent instructions together; re-run fixed and adversarial examples after changes; record failures and reviewer outcomes; keep publication under a security owner’s control.

Before a pilot, agree on source access, confidentiality, ownership and approval criteria. Measure misses and unnecessary escalations using approved non-sensitive examples. No live agent maintenance or operational savings are demonstrated here.
